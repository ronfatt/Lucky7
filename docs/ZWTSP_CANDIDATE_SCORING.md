# ZWTSP Phase 6 Candidate Scoring Specification (组合评分规范)

## 1. 组合综合评分公式 (Combination Score Formula)

对任一候选组合 $C = [d_1, d_2, d_3, d_4]$，其综合模型得分定义为：

$$S_{\text{combo}}(C) = \sum_{k=1}^{6} W_k \cdot f_k(C)$$

| 维度代码 | 维度名称 | 默认权重 $W_k$ | 计算逻辑说明 |
| :--- | :--- | :--- | :--- |
| **Digit Strength** | 单字综合强度均值 | $35\%$ | $\frac{1}{4} \sum_{i=1}^4 S_{\text{digit}}(d_i)$，反映该组合包含数字的基础气场实力 |
| **Personal DNA** | 先天DNA重叠度 | $15\%$ | 组合数字落在个人核心数字DNA中的比例与本命五行加成 |
| **Daily Activation** | 当日流日激活匹配 | $15\%$ | 组合各位数字在今日干支节气激活体系中的协同共振分 |
| **Reality Signal** | 现实信号契合度 | $15\%$ | 组合数字与用户今日记录的现实车牌/订单等信号的重合与形态亲和力 |
| **Direction Match** | 空间方位契合度 | $10\%$ | 组合在当前首选吉利的方位扇区（八方空间数理矩阵）中的激活度 |
| **Pattern Balance** | 数理形态结构分 | $10\%$ | 和值（Sum）、数字根（Digital Root）、奇偶比、高低比的均衡度评价 |

---

## 2. 评级区间划分 (Model Tiers)

| 分值区间 | 等级代码 | 中文等级名称 | 状态语义与指导原则 |
| :--- | :--- | :--- | :--- |
| **85.0 ~ 100.0** | `VERY_STRONG` | 极强共振 | 各维度时空要素高度集中吻合，气场充盈 |
| **70.0 ~ 84.9** | `STRONG` | 强力契合 | 多维度协同顺畅，主次分明 |
| **50.0 ~ 69.9** | `NORMAL` | 平和普通 | 气象中正，无突出共振亦无明显刑克 |
| **30.0 ~ 49.9** | `WEAK` | 偏弱耗散 | 维度之间存在冲突，要素协同度偏低 |
| **0.0 ~ 29.9** | `LOW` | 极低警戒 | 气场相悖或严重缺位，建议审慎对待 |

---

## 3. 模型分值与模型一致性分离 (Score vs Consistency Separation)

- **Model Score (模型得分)**：体现加权综合数学计算结果。
- **Model Consistency (模型一致性)**：评价不同层次（DNA、流日、方位、现实信号）之间是**互相印证**还是**彼此冲突**。
  - 若 DNA 指向水，但流日旺火克水，即便加权分尚可，一致性亦标定为 `LOW`。
  - 严禁将二者粗暴混为一谈。
