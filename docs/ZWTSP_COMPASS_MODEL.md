# ZWTSP Phase 4 Compass Model Specification (个人时空罗盘规范)

## 1. 概览与设计哲学

「位」（Position / Spatial Direction）是紫微时空数字预测系统（ZWTSP）六大支柱「时·位·象·数·行·验」中的第二支柱。
在 Phase 4 中，罗盘是个人先天气场与今日时空方位共振的可视化载体。

### 核心设计准则
- **专业与典雅**：采用 Obsidian 曜石黑背景（`#070A12`）、暗金色（`#D4AF37` / `#C5A059`）、天青与琉璃质感。
- **正北朝上固定视图（North-up Static View）**：
  - 传统天体及地理罗盘标准：正北 $0^\circ$ 位于罗盘正上方（12点钟方向）。
  - 顺时针旋转：
    - 北 (N, $0^\circ$ / $360^\circ$)
    - 东北 (NE, $45^\circ$)
    - 东 (E, $90^\circ$)
    - 东南 (SE, $135^\circ$)
    - 南 (S, $180^\circ$)
    - 西南 (SW, $225^\circ$)
    - 西 (W, $270^\circ$)
    - 西北 (NW, $315^\circ$)
- **禁止事项**：
  - 严禁调用手机硬件陀螺仪/磁力计强制随手部晃动旋转（避免用户产生误导性物理定位错觉）。
  - 严禁接入地图 API（Google / Baidu / 高德）或推荐彩票投注站（Phase 5 范畴）。
  - 严禁声称方位能够保证中奖。

## 3. 罗盘视觉层次架构 (SVG 渲染规范)

罗盘采用纯矢量 SVG 渲染，分为 5 个同心圆层：

1. **外刻度环 (Outer Azimuth Dial)**：
   - 包含 $360^\circ$ 细分刻度线，每 $5^\circ$ 小刻度，每 $15^\circ$ 中刻度，每 $45^\circ$ 大刻度带度数标字（$0^\circ, 45^\circ, 90^\circ...$）。
2. **八方扇区环 (Eight Octant Sectors)**：
   - 8 个 $45^\circ$ 环状扇区切片（Pie / Annular slices）。
   - 扇区根据「今日综合时空方位得分」着色填充：
     - **极吉 (85-100)**: 曜金辉光高亮、带流光脉冲描边。
     - **次吉 (70-84)**: 温润金琥珀。
     - **平吉 (55-69)**: 典雅青黛 / 幽蓝。
     - **平淡 (40-54)**: 深灰蓝半透明。
     - **慎用 (<40)**: 幽暗绛红微弱警示。
   - 悬停或选中某扇区时，联动右侧/下方详细信息面板。
3. **后天八卦与卦象文字环 (Bagua Symbol Ring)**：
   - 显示 ☰ ☱ ☲ ☳ ☴ ☵ ☶ ☷ 易经符号与卦名（坎、艮、震、巽、离、坤、兑、乾）。
   - 标注对应的五行属性小徽标（金、木、水、火、土）。
4. **数理共振环 (Digit Resonance Ring)**：
   - 显示该方位洛书本宫数，以及在该方位下今日激活度最高的数字（0-9 共振映射）。
5. **中心天心十道与太极枢纽 (Central Pivot & Taiji Hub)**：
   - 金色十字准星（天心十道）。
   - 中心圆形晶球，展示今日全局气象等级、最佳方位摘要、方向一致性评分与信赖度。
